# Блог nic-ecolog.ru (NIC-010)

Статьи — Markdown-файлы в этой папке. Сборщик `scripts/build-pages.mjs` превращает их в `/blog/` и `/blog/{slug}/`. Пакет задачи — `seo_geo/tasks/NIC-010-blog.json`.

## Файл статьи

`content/blog/{slug}.md`, в начале — блок полей:

```
---
title: Заголовок для поиска, до 60 знаков
description: Описание для поиска, до 160 знаков
h1: Заголовок на странице
slug: адрес-статьи
status: draft            # draft | published
date: 2026-10-01         # дата публикации (YYYY-MM-DD)
updated: 2026-10-01      # дата последнего изменения
services: [plata-nvos, autsorsing-ekologa]   # страницы /uslugi/{slug}/, с которыми связана статья
source: seo_geo/nic-ecolog/stati/…           # черновик с факт-чеком (не публикуется)
cover: kategorii-nvos-pp-636.webp             # необязательно: файл в assets/blog/, 1600×900
cover_alt: Описание картинки                  # обязательно, если есть cover
---
```

Сборка падает с понятной ошибкой, если:
- нет обязательного поля;
- title длиннее 60 знаков или description длиннее 160;
- в `services` указана услуга без страницы.

Текст статьи поддерживает:
- заголовки `##` и `###`, абзацы;
- списки `-` и `1.`;
- таблицы, `**жирный**`, ссылки `[текст](/uslugi/…/)`.

Заголовок H1 в тексте не пишут, он берётся из поля `h1`.

Обложка (`cover`) показывается под датой статьи и в карточке на `/blog/`, идёт в `og:image` и в разметку `Article.image`. Файлы — `assets/blog/`, 1600×900, WebP до ~200 КБ. Требования к стилю — в `seo_geo/nic-ecolog/stati/tz_izobrazheniya_blog.md`.

## Черновики и публикация

- `npm run pages:build` — только `status: published`. Это сборка для прода.
- `BLOG_DRAFTS=1 npm run pages:build` — ещё и черновики. Для локального превью и devpreview (workflow `deploy-devpreview.yml` собирает так).
- Черновики никогда не попадают в `sitemap.xml`.
- Пока нет ни одной опубликованной статьи, прод-сборка не содержит `/blog/` и ссылок «Блог».

Статья публикуется только после факт-чека экспертом НИЦ. Метки `[ФАКТ-ЧЕК]`, вопросы эксперту и таблица источников живут в черновике в `seo_geo`, на сайт не идут.

## Что появляется вместе с блогом

Когда в сборке есть хотя бы одна статья:
- пункт «Блог» в меню и подвале страниц услуг;
- ссылка «Блог» в подвале главной и `lab.html`;
- блок «Статьи по теме» на страницах услуг из `services`;
- блок «Услуги по теме» в самой статье.

## Проверки

```
BLOG_DRAFTS=1 npm run pages:build
npm run pages:preview          # http://localhost:8766
npm run pages:qa-wave1         # страницы услуг, ссылки с главной и lab.html
BLOG_DRAFTS=1 npm run pages:qa-blog
```

`pages:qa-blog` проверяет:
- код 200;
- уникальные title и H1, canonical на себя, `index, follow`;
- счётчик Метрики;
- JSON-LD `Article` / `Blog` + `BreadcrumbList`;
- нет остатков разметки и служебных меток;
- все внутренние ссылки ведут на файлы в `docs/`;
- обратные ссылки со страниц услуг;
- черновиков нет в sitemap, без `BLOG_DRAFTS` черновики не собираются.
