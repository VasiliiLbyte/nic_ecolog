# MOBILE PLAYBOOK — практики мобильной адаптации

> **Forward-looking.** Это целевые практики для **улучшения** мобильной версии.
> Текущее реализованное состояние — в `design-system/pages/mobile.md`.
> База «почему» и ссылки — в `design-system/references/mobile-responsive.md`.

Применяется к главной (`NIC Ecolog - Главная v2.dc.html` → `index.html`) и лаборатории
(`Ecolog-Lab.html` → `lab.html`).

---

## Принципы

1. **Mobile-first по мышлению.** Проектируем от 360px вверх; сложность добавляем на больших экранах.
2. **Плавность вместо ступенек.** Тип и ритм — через `tokens/fluid.css` (`--fluid-text-*`, `--fluid-space-*`),
   а не скачками на брейкпоинтах.
3. **Контейнер важнее вьюпорта.** Карточки адаптируются через container queries — работают в любой раскладке.
4. **Палец — главный курсор.** Крупные таргеты, thumb-zone, безопасные отступы от краёв.
5. **Бренд не меняется на мобайле** — те же палитра, шрифты, тон.

---

## 1. Touch targets и thumb-zone

- Интерактив (ссылки, кнопки, поля, бургер, пункты меню): **min 44×44 CSS-px** (минимум WCAG — 24, цель — 44).
- Зазор между таргетами ≥ **8px**; отступ от края экрана ≥ **16px**.
- Первичный CTA — в нижней трети (зона большого пальца).
- **Статус:** меню-оверлей уже `min-height:44px`. Проверить: телефон/почта в футере, «политика конфиденциальности»,
  ссылки «Страница услуги», dot-таргеты.

## 2. Safe-area (вырезы, home-indicator)

- `<meta name="viewport" content="... viewport-fit=cover">`.
- Фикс-шапка и sticky-CTA учитывают вырез:
  ```css
  padding-top: max(12px, env(safe-area-inset-top));
  padding-bottom: max(12px, env(safe-area-inset-bottom));
  ```
- Полноширинные тёмные секции — проверить, что фон уходит под вырез, а контент — нет.

## 3. Sticky-CTA на мобильном (закрывает пробел ТЗ, п.6)

Целевой паттерн: закреплённая снизу панель на телефоне с первичным действием.

- Показывать при `≤720px`, появляется после ухода hero из вида (IntersectionObserver), прячется у формы `#zayavka`.
- Состав: одна кнопка «Получить консультацию» (или «Заказать исследование») + иконка звонка `tel:`.
- Высота таргета ≥ 44px; нижний отступ — `env(safe-area-inset-bottom)`; не перекрывает контент (добавить
  `scroll-padding-bottom`/нижний `padding` странице).
- Уважать `prefers-reduced-motion` (без «прыжков» появления).
- Референсы паттерна: Mobbin (см. inspiration-galleries.md).

## 4. Container queries для карточек

Перевести сетки карточек (услуги, «Почему выбирают нас», «Лицензии») с завязки на `data-cols4`/вьюпорт
на контейнер:
```css
.cards { container-type: inline-size; }              /* контейнер для @container-запросов */
@container (min-width: 640px) { .card-grid { grid-template-columns: repeat(2,1fr); } }
@container (min-width: 960px) { .card-grid { grid-template-columns: repeat(3,1fr); } }
```
Плюс: карточка одинаково корректна в основной сетке и в узких контекстах.

## 5. Fluid-типографика и ритм

- Ключевые заголовки/лиды → `--fluid-text-*` (напр. h2 → `--fluid-text-4`, hero → `--fluid-text-6`).
- Вертикальные отступы секций → `--fluid-space-*` (секция → `--fluid-space-3xl`).
- Цель: убрать резкие изменения размеров между 720/1060 и «дышащий», но не рвущийся ритм.

## 6. Взаимодействия для тач

- Всё, что раскрывается по hover (описания карточек услуг), имеет фолбэк `@media (hover:none)` —
  контент доступен по тапу/изначально виден (уже реализовано у `[data-svc]`; распространить на новые интерактивы).
- Высоты hero — `dvh`/`svh` вместо `vh` (корректно с адресной строкой).
- Убрать hover-only состояния как единственный способ получить информацию.

## 7. Бюджет производительности (mobile)

| Метрика | Цель |
|---------|------|
| LCP | < 2.5s |
| CLS | < 0.1 |
| INP | < 200ms |
| PageSpeed (mobile) | ≥ 85 (цель ТЗ) |

- Проектные фото → WebP/AVIF, явные `width/height`, `loading="lazy"` для внеэкранных, `srcset`.
- `preload` hero-шрифтов; `font-display: swap` (есть).
- Не грузить тяжёлый декор (blur-blobs) в полном размере на мобайле — упростить/уменьшить.
- Детали и ссылки — `references/accessibility-performance.md`.
