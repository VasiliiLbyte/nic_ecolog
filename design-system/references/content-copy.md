# Контент и копирайтинг

Ресурсы для **качества текстов** лендинга. Тон бренда НИЦ «Эколог»: спокойная экспертность,
data-led, по-русски, без пафоса и greenwashing, без emoji (см. `MASTER.md`).

---

### MarketingExamples (Harry Dry)
- **Что:** разборы лендингов и копирайтинга на реальных примерах; правила «visualise / falsifiable / unique».
- **Почему лучший:** учит писать конкретно и проверяемо, «удаляя лишние слова».
- **Применить:** заголовки и буллеты — **фальсифицируемые и конкретные** («98% документации согласовано
  без замечаний», «одна команда по одному адресу»), а не общие обещания. Убрать вводные слова.
- **Ссылка:** https://marketingexamples.com/

### Julian Shapiro — Startup Handbook: Landing Pages
- **Что:** пошаговая методология лендинга + упражнение value proposition (Bad Alternative → Better Solution → Action Statement).
- **Почему лучший:** системный способ вывести сильный оффер и структуру доверия.
- **Применить:** прогнать услуги/преимущества через таблицу value-prop; проверить, что hero-оффер —
  «Action Statement», а не описание процесса. Знакомая структура страницы = меньше барьеров.
- **Ссылка:** https://www.julian.com/guide/startup/landing-pages

### Demand Curve — Above the Fold / Landing page playbooks
- **Что:** практические шаблоны первого экрана и структуры конверсии.
- **Почему лучший:** конкретные формулы «оффер + подзаголовок + доказательство + CTA».
- **Применить:** усилить первый экран (оффер → одно предложение пользы → строка доверия → CTA — у нас это есть, отревьюить).
- **Ссылка:** https://www.demandcurve.com/playbooks/above-the-fold

### Nielsen Norman Group — Writing for the Web
- **Что:** доказательные правила веб-текста (сканируемость, front-loading, списки, объём).
- **Почему лучший:** основано на исследованиях чтения с экрана.
- **Применить:** абзацы короче, главное — в начало предложения; тех-термины (ПНООЛР, СЗЗ, ОВОС) сопровождать
  человеческой расшифровкой (уже сделано на карточках услуг).
- **Ссылка:** https://www.nngroup.com/articles/how-users-read-on-the-web/

### GOV.UK — Content Design / Style Guide
- **Что:** эталон ясного, доступного, неканцелярского языка на масштабе гос-сервисов.
- **Почему лучший:** дисциплина «пиши для задачи пользователя, простыми словами».
- **Применить:** избегать канцелярита в описаниях услуг; CTA — глаголом от лица пользователя
  («Заказать исследование», «Получить консультацию»).
- **Ссылка:** https://www.gov.uk/guidance/content-design

## Как применять к НИЦ «Эколог» (фильтр бренда)
- **Тон:** уверенный, точный, без восклицаний и «лидер рынка».
- **Доказательство вместо декларации:** цифры, объекты (Лахта Центр, Мариинский театр, порты, МОЭК), метрики.
- **Русский язык:** без англицизмов там, где есть точный русский термин; аккуратные тире и кавычки «ёлочки».
- **Никакого greenwashing:** «умная экология = измеримые величины», а не листики и общие лозунги.
