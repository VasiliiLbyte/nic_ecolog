# Дизайн-основы + современный CSS

Ресурсы, поднимающие планку **визуального дизайна** и дающие **инструменты** для чистого,
масштабируемого CSS. Формат: **что · почему лучший · как применить к НИЦ Эколог · ссылка**.

---

## Принципы и системы дизайна

### Refactoring UI (Adam Wathan, Steve Schoger)
- **Что:** практический канон визуального дизайна для не-дизайнеров: иерархия, spacing,
  типографика, цвет, тень, «дизайн через убирание».
- **Почему лучший:** самый концентрированный источник приёмов, которые сразу видно на макете.
- **Применить:** уже отражено в v2 (иерархия через размер/вес/цвет, а не рамки; hairline-границы
  `rgba(11,92,96,.12)`; тени редко и мягко). Использовать как чек при добавлении секций.
- **Ссылка:** https://www.refactoringui.com/

### Laws of UX (Jon Yablonski)
- **Что:** карманный справочник психологических законов (Fitts, Hick, Miller, Jakob, эстетика-юзабилити).
- **Почему лучший:** быстрый язык для обоснования UX-решений.
- **Применить:** закон Хика → не раздувать hero-CTA до трёх; закон Фиттса → крупные таргеты на мобайле
  (см. MOBILE-PLAYBOOK); Jakob's Law → знакомая структура лендинга (hero → доверие → услуги → CTA).
- **Ссылка:** https://lawsofux.com/

### Material 3 · Apple HIG · GOV.UK Design System
- **Что:** три эталонных системы — токены/тема (M3), тактильность и safe-area (HIG),
  доступность и контент-дисциплина (GOV.UK).
- **Почему лучшие:** проверенные на масштабе решения по состояниям, фокусу, формам, таргетам.
- **Применить:** **брать паттерны, не визуал.** У GOV.UK — модель доступных форм и «error summary»
  (пригодится форме заявки); у HIG — safe-area и thumb-zone; M3 — дисциплина токенов (у нас `tokens/`).
  Палитру/скругления/тени НЕ копируем — они у нас брендовые.
- **Ссылки:** https://m3.material.io/ · https://developer.apple.com/design/human-interface-guidelines ·
  https://design-system.service.gov.uk/

### Nielsen Norman Group (NN/g)
- **Что:** исследовательская база по юзабилити (10 эвристик, паттерны, чтение с экрана).
- **Почему лучший:** доказательная, а не вкусовая база.
- **Применить:** эвристики как ревью-линза; «F-pattern/чтение по диагонали» → важное в первый экран.
- **Ссылка:** https://www.nngroup.com/articles/

## Современный CSS — инструменты

### Utopia.fyi — fluid type & space
- **Что:** метод и калькулятор плавных шкал типа/отступов на `clamp()` без брейкпоинтов.
- **Почему лучший:** убирает «ступеньки» размеров между брейкпоинтами — текст и ритм тянутся плавно.
- **Применить:** **уже внедрено** → `tokens/fluid.css` (`--fluid-text-*`, `--fluid-space-*`),
  откалибровано под бренд (h2 34→52, hero 48→92). На этапе улучшения перевести ключевые заголовки на эти токены.
- **Ссылка:** https://utopia.fyi/

### Open Props (Adam Argyle)
- **Что:** библиотека дизайн-токенов как CSS-переменных (без сборки, ~1.5KB core).
- **Почему лучший:** эталон организации токенов; можно свериться с именованием и набором (easings, sizes, shadows).
- **Применить:** как **референс для наших `tokens/`** (не подключаем целиком — палитра/шрифты брендовые).
  Полезны его `--ease-*` и размерные шкалы как ориентир.
- **Ссылка:** https://open-props.style/

### Every Layout (Heydon Pickering, Andy Bell)
- **Что:** набор устойчивых layout-примитивов (Stack, Cluster, Sidebar, Switcher, Grid) на «intrinsic» CSS.
- **Почему лучший:** «будь браузеру наставником, а не микроменеджером» — раскладки, которые сами адаптируются
  без десятка медиа-запросов.
- **Применить:** «Switcher»/«Cluster» вместо ручных `data-cols4` для карточек услуг/преимуществ/лицензий;
  «Stack» для вертикального ритма секций. Кандидат на рефактор сеток при мобильном улучшении.
- **Ссылка:** https://every-layout.dev/

### Modern CSS (Stephanie Eckles) · Piccalilli «Complete CSS»
- **Что:** актуальные разборы решений (fluid, grid, `:has()`, container queries, формы, focus).
- **Почему лучшие:** рецептурные, production-ready, без фреймворков.
- **Применить:** источник конкретных сниппетов при улучшении (например, container-query карточки — см. mobile-responsive.md).
- **Ссылки:** https://moderncss.dev/ · https://piccalil.li/

### Современный CSS reset (Andy Bell / Josh Comeau)
- **Что:** минимальные доступные reset'ы (box-sizing, media, form inheritance, reduced-motion).
- **Почему лучшие:** кроссбраузерный и кросс-девайсный базис без «обнуления» полезных дефолтов.
- **Применить:** **уже внедрено** → `tokens/reset.css`.
- **Ссылки:** https://andy-bell.co.uk/a-more-modern-css-reset/ · https://www.joshwcomeau.com/css/custom-css-reset/
