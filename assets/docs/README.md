# Документы для блока «Лицензии и документы»

Сюда кладутся реальные PDF-файлы, на которые ссылаются плитки на главной
(секция `#litsenzii` в `NIC Ecolog - Главная v2.dc.html`).

Ожидаемые имена файлов (замените плейсхолдеры реальными документами):

| Плитка | Имя файла | Статус |
|--------|-----------|--------|
| Аттестат аккредитации лаборатории «Аналитик Лаб» (`RA.RU.516478`, от 25.12.2025) | `attestat-akkreditacii.pdf` | в репозитории |
| Выписка из реестра аккредитованных лиц | `vypiska-reestr.pdf` | ожидает файл |
| Лицензия на обращение с отходами I–IV классов | `licenziya-othody.pdf` | ожидает файл |
| Сертификаты системы менеджмента (ISO 9001, 14001) | `sertifikaty-iso.pdf` | ожидает файл |

После добавления файлов пересоберите демо: `npm run pages:build`.
Файлы копируются в `docs/assets/docs/` автоматически.
