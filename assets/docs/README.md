# Документы для блока «Лицензии и документы»

Сюда кладутся реальные PDF-файлы, на которые ссылаются плитки на главной
(секция `#litsenzii` в `NIC Ecolog - Главная v2.dc.html`).

Ожидаемые имена файлов (замените плейсхолдеры реальными документами):

| Плитка | Имя файла |
|--------|-----------|
| Аттестат аккредитации лаборатории «Аналитик Лаб» | `attestat-akkreditacii.pdf` |
| Выписка из реестра аккредитованных лиц | `vypiska-reestr.pdf` |
| Лицензия на обращение с отходами I–IV классов | `licenziya-othody.pdf` |
| Сертификаты системы менеджмента (ISO 9001, 14001) | `sertifikaty-iso.pdf` |

После добавления файлов пересоберите демо: `npm run pages:build`.
Файлы копируются в `docs/assets/docs/` автоматически.
